O santuário

Quem mantém a chama acesa, o que guia cada inscrição e como este lugar se sustenta.

Uma obsessão simples

Gena Souls Like nasce de uma obsessão simples: os jogos que exigem algo de você merecem um lugar próprio, não uma tag num site generalista. Aqui, cada notícia é verificada com fonte, cada data é real, e o arquivo do gênero é tratado com o respeito de quem levou décadas de mortes para construí-lo.

O santuário cobre o mundo dark dos games: RPG de ação, soulslikes e os blockbusters que herdaram essa chama — do King's Field de 1994 ao presente. Notícias atualizadas diariamente por um robô que só publica o que passa no filtro do gênero; ofertas e jogos grátis conferidos ao vivo nas fontes oficiais.

Como este lugar se sustenta

A Loja do Cinza e alguns links de recomendação sustentam o site: como Associados Amazon, ganhamos comissão por compras qualificadas feitas através deles, sem custo extra para você. As ofertas exibidas vêm direto das APIs oficiais das lojas (Epic Games Store, via CheapShark para Steam, GOG e Humble); nunca alteramos um preço e nenhum link é encurtado para inflar métricas.

Projeto de fã, sem afiliação com FromSoftware, Bandai Namco, Sony ou qualquer publisher. Todas as marcas citadas pertencem aos seus detentores. Notícias linkam às fontes originais; trailers são reproduzidos via YouTube dos canais oficiais. Dados de busca de jogos via RAWG.io.

Que a chama o guie, cinza.
